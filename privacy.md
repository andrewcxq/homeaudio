# HomeAudio Privacy Policy

Last updated: 27 October 2026

HomeAudio is a personal, non-commercial project maintained
by GitHub user andrewcxq for use within the owner's household.

## Google Drive access

HomeAudio requests the Google Drive read-only OAuth scope.
This permission can allow access to file metadata and contents
throughout the authorized account's Drive. It is not a
Google-enforced permission limited to one music folder.

The local playback configuration is intended to serve only
the audio folder selected by the owner.

## Use of data

File names, metadata, and selected audio contents are used
to locate and stream audio for playback on household Sonos
speakers through rclone and Home Assistant.

HomeAudio does not use Google Drive data for advertising,
sell it, or use it to train AI models.

## Storage and sharing

OAuth credentials are stored on owner-controlled devices
used to configure or operate the application. They are not
published in this website or its GitHub repository.

Playback involves transferring audio through the home
system to the selected Sonos speakers. Temporary buffering
may occur. This website does not host the audio library.

Google Drive data is not intentionally made publicly
available by HomeAudio.

## Revoking access and deletion

The owner can revoke HomeAudio's access through Google
Account settings and remove the local rclone configuration,
credentials, and any local cached files.

Revoking access does not delete the original Drive files.

## Website hosting

This informational website is hosted by GitHub Pages.
GitHub may process visitor connection information under
its own privacy policy.
