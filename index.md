# HomeAudio

HomeAudio is a personal, non-commercial home audio project
maintained by GitHub user andrewcxq.

It uses rclone and Home Assistant to access audio files in
the owner's Google Drive and play selected audio on Sonos
speakers within the owner's home network.

Google Drive access requires the owner's explicit OAuth
authorization. The application requests read-only access.
It does not upload, modify, or delete Google Drive files.

This website contains application information only.
It does not host audio files or Google account credentials.
